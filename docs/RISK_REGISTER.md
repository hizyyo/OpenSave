# openSave Risk Register

> Historical risk inventory from the broad product review. Risks tied only to removed features remain for reference, but they are not active roadmap commitments. See `docs/PRODUCT_ROADMAP.md` and `sessions/README.md` for current scope.

Review date: 2026-08-28

## Scale

- Likelihood: `Low`, `Medium`, `High`, `Almost certain`.
- Impact: `Moderate`, `High`, `Critical`.
- Detection names the exact evidence or test required. A passing current fixture is not detection unless stated.
- Owner session refers to `sessions/NN-*.md`.
- Stop/go criteria are release/dependency gates, not general aspirations.

## Release Stop Conditions

The following conditions block claims, not merely implementation milestones:

- Do not claim “everything the browser received” while R01, R02, R23, or R24 remains unresolved.
- Do not claim capture completeness from the current percentage while R27 remains unresolved.
- Do not claim arbitrary static-host portability while R06/R32 remain unresolved; the current supported contract is origin root.
- Do not claim hermetic replay while R07, R09, or R10 lacks behavioral validation.
- Do not claim a capture is safe to share while R39/R40/R46 lacks a sanitized default and scanner.
- Do not begin standards evidence export while R01/R03/R15/R23 lacks passing gates.
- Do not implement incremental capture before immutable hashes, state compatibility, and validator gates pass.

## Phase Gates

### Gate A: Before Session 02

- Controlled corpus reliably detects missing resource, external request, runtime exception, wrong route, burst body omission, and refetch provenance.
- Ten repeated deterministic runs have no more than one flaky run, matching Session 01 stop/go.

### Gate B: Before Session 03

- Graph preserves GET/POST variants, redirects, repeated responses, response metadata, target provenance, and separate refetch records.
- V1 archive/report compatibility differences are documented and approved.

### Gate C: Before Session 04/05

- Durable mission/body cleanup succeeds for success, cancel, detach, reload, quota failure, and abandoned export.
- Large fixture no longer depends on one in-memory body map/message.

### Gate D: Before Session 06/07

- Original evidence remains immutable after all typed transforms.
- Parser tests cover all syntax families and ordinary JavaScript strings are not rewritten.
- Live checkpoints are route/frame-linked and privacy-redacted.

### Gate E: Before Session 08+

- Rendered routes are distinct from fetch-only pages.
- Replay is mount-aware, publisher SW cannot take over, repeated APIs replay deterministically, and every miss has a reason.
- First-load and controlled-load zero-egress tests pass.

### Gate F: Before Sessions 10-14 And 18-22

- Validator opens actual generated artifacts and distinguishes capture, transform, replay, privacy, and infrastructure failures.
- Later writers/extractors consume graph/body-store interfaces and do not add parallel capture paths.
